# 

Play YouTube videos in the background on Android Firefox.

## Installation

### Firefox
Install directly from mozilla app store:
https://addons.mozilla.org/fi/firefox/addon/backstage-play/




### Chrome (Desktop)

1. Download `ytbackground-chrome.zip` to your device
2. Unzip the file to a folder
3. Open Chrome and go to `chrome://extensions`
4. Enable **Developer mode** (toggle in top right corner)
5. Click **Load unpacked**
6. Select the unzipped folder
